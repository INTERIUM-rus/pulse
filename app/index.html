    Эффекты

    «Спокойно» — без вспышек, молний и дропов. «Под настроение»: на медленной и тихой музыке краски блекнут и уходят в холодные тона, движение замедляется.

    Звук

    Эквалайзер, эхо и плавный переход работают для треков из медиатеки (кроме YouTube). На YouTube меняется только скорость.

    Своя тема

    Будильник

    Утром Pulse сам включит музыку и плавно поднимет громкость за минуту. Pulse должен быть запущен (можно свернуть или «Тихо в трее»).

    Пресеты

    Приложение

    В OBS: Источник → Браузер → адрес http://localhost:53690/, размер 1920×1080. Без текста песни: ?lyrics=0, плашка справа: ?pos=right.

    Если YouTube не открывается без VPN. Работает только для адресов YouTube через открытый zapret, Windows попросит права администратора. С включённым VPN не нужно.
