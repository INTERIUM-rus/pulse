Политика конфиденциальности

Действует с 31 октября 2026 года.

Pulse — приложение для Windows: музыкальный визуализатор, медиатека и профиль пользователя. Здесь написано, какие данные Pulse использует, зачем и как ты можешь их удалить.

1. Что остаётся только на твоём компьютере

  • Звук. Pulse анализирует звук, который играет в Windows, чтобы рисовать визуал под бит. Звук обрабатывается только на компьютере, никуда не записывается и не отправляется.
  • Что сейчас играет. Название трека, исполнитель и обложка берутся из системных «Сейчас играет» Windows.
  • Свои файлы. Музыка из выбранных тобой папок читается локально и никуда не загружается.
  • Настройки, история и статистика без входа в аккаунт хранятся только на компьютере.

2. Что хранится в облаке, если ты вошёл в аккаунт

  • Данные входа: адрес почты; при входе через Google — также имя и ссылка на аватарку из Google-аккаунта; при входе через Telegram-бота — числовой ID, имя и username в Telegram (почта в этом случае не нужна).
  • Профиль: ник, описание, аватарка и баннер, которые ты сам загрузил.
  • Медиатека: избранное, плейлисты, история и статистика прослушиваний — чтобы они были на любом компьютере.
  • Друзья: заявки в друзья и список друзей.
  • «Сейчас слушает»: название и исполнитель текущего трека и время, когда он играл. Это видят твои друзья.
  • «Продолжить на другом устройстве»: последний трек (название, исполнитель, ссылка на него), секунда, на которой ты остановился, тип устройства (компьютер, телефон или браузер) и случайный номер установки Pulse — чтобы на другом устройстве предложить продолжить с того же места. Хранится вместе с «сейчас слушает».

Ник, описание, аватарку, баннер и «сейчас слушает» могут видеть другие вошедшие пользователи Pulse (например, при поиске друзей). Остальное видишь только ты.

Данные хранятся у сервиса Supabase (сервер в ЕС). Доступ к записям защищён правилами: каждый пользователь может читать и менять только свои данные.

3. Сторонние сервисы

  • YouTube. Поиск и воспроизведение треков из YouTube работают через YouTube API Services. Используя эту функцию, ты соглашаешься с Условиями использования YouTube. Обработка данных Google описана в Политике конфиденциальности Google. Отозвать доступ Pulse к данным Google можно на странице настроек безопасности Google.
  • Telegram. Вход через бота @pulsemusic812_bot работает через Telegram: бот получает только то, что Telegram передаёт при нажатии «Запустить», и отвечает одним сообщением.
  • Тексты песен загружаются с LRCLIB по названию и исполнителю трека.
  • Каталоги музыки: Internet Archive, ccMixter и Deezer получают только поисковый запрос.
  • Вайб (ИИ-собеседник) работает только для вошедших в аккаунт. Сообщения, которые ты ему пишешь, название трека, который сейчас играет, и день недели со временем передаются через сервер Pulse одному из ИИ-сервисов — Google Gemini, Groq, OpenRouter или DeepSeek (какой сейчас доступен), чтобы получить ответ. Почта, имя и другие данные аккаунта ИИ-сервису не передаются. История переписки с Вайбом хранится только на твоём устройстве; на сервере Pulse считается лишь количество сообщений за день (для дневного лимита). Не пиши Вайбу личные данные.
  • Голосовые команды работают только по нажатию кнопки 🎙 (или клавиши J), микрофон включается на несколько секунд. В приложении для Windows речь распознаётся прямо на устройстве (Vosk), запись никуда не отправляется. В браузерах Chrome и Edge распознаёт сам браузер (Google или Microsoft), в приложении для Android — системный голосовой ввод телефона; по их правилам.

Pulse не показывает рекламу, не продаёт и не передаёт твои данные третьим лицам для рекламы.

4. Анонимная статистика и отчёты об ошибках

  • Статистика. Раз в день Pulse отправляет случайный номер установки (не связан с аккаунтом и с тобой), версию приложения, платформу (Windows, сайт или телефон) и дату. Так видно, сколько людей пользуется Pulse и какие версии у них стоят.
  • Отчёты об ошибках. Если Pulse падает или что-то ломается, отправляется текст ошибки, версия, версия Windows или браузера и тот же номер установки. Ни треков, ни переписки, ни личных данных в отчётах нет.
  • Читать эти данные может только разработчик. Отключить отправку можно в Настройки → Приложение → «Анонимная статистика».
  • Оверлей для стрима работает только на твоём компьютере (адрес localhost) и наружу ничего не отправляет.

5. Как удалить данные

Выйти из аккаунта можно в любой момент в разделе «Аккаунт». Чтобы полностью удалить аккаунт и все данные в облаке, напиши на dz904951@gmail.com с той почты, к которой привязан аккаунт — удалим в течение 30 дней. Локальные данные удаляются вместе с папкой %LOCALAPPDATA%\Pulse.

6. Дети

Pulse не предназначен для детей младше 13 лет и сознательно не собирает их данные.
